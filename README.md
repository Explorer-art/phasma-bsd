# Phasma BSD
Phasma BSD – это монозадачная 32-битная операционная система под архитектуру x86, написанная на C и языке ассемблера. Для загрузки используется загрузчик GRUB.

Не стоит обольщаться из-за похожего суффикса в названии – с технической точки зрения Phasma не похожа на UNIX-подобные ОС, такие как Linux или FreeBSD. Она скорее схожа с системами DOS, так как тоже является монозадачной и использует файловую систему FAT (FAT32), но при этом работает в 32-битном режиме, что дает больше возможностей и позволяет использовать более актуальные механизмы управления памятью и прерываниями.

Благодаря отсутствию многозадачности, в ядре нет сложных механизмов и структур, таких как планировщик и контекст процесса. Это делает код ядра простым и легким, укладывающимся всего-лишь в ~2000 строк кода, что позволяет легко изучить устройство операционной системы.

Целью Phasma BSD является:
- желание автора (меня) создать простую ОС, потому что ему это просто в кайф;
- изучение основ работы операционных систем на простом примере.

### Установка зависимостей
Для компиляции используется GCC и NASM, для автоматизации сборки проекта - Make. Так же для работы с образом файловой системы необходим набор утилит mtools. В качестве виртуальной машины для запуска ОС используется QEMU, но вы можете использовать и другие. Все основные пакеты для сборки устанавливаются командой (Debian/Ubuntu):
```
sudo apt install gcc nasm make mtools qemu-system grub-pc
```

Так же вы можете установить дополнительные пакеты для отладки с помощью Bochs (неактуально, так как мне Bochs падает при попытке запуска):
```
sudo apt install bochs bochs-x bochs-sdl bochsbios vgabios
```

### Сборка
Проект состоит из трех независимых директорий: kernel (ядро), libc, userland (программы пространства пользователя). В каждой из этих директорий есть свой Makefile, который отвечает именно за свою директорию, а всех их воедино собирает главный Makefile, который находится в корне проекта. Для сборки достаточно написать команду:
```
sudo make
```
Для сборки нужно использовать права root из-за необходимости монтировать образ с операционной системой к файловой системе.

### Запуск
Запустить ОС на виртуальной машине можно написав команду:
```
make run
```
или вручную
```
qemu-system-x86_64 -drive format=raw,file=phasma.img,if=ide,index=0
```
